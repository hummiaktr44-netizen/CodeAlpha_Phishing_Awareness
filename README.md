# CodeAlpha_Phishing_Awareness

Interactive phishing awareness training module (CodeAlpha Cyber Security Internship, Task 2).

**Live demo:** https://hummiaktr44-netizen.github.io/CodeAlpha_Phishing_Awareness/phishing_awareness_training.html

## What it covers
- What phishing is and its types (mass, spear phishing, whaling, smishing, vishing)
- How to recognize phishing emails (interactive red-flag email example)
- How to recognize fake websites (URL comparison examples)
- Social engineering tactics
- Best practices to avoid becoming a victim
- Real-world examples
- A 6-question interactive quiz with instant feedback

## How to use
Open `phishing_awareness_training.html` in any browser. No installation needed.
